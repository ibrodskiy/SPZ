# Сайт проверки знаний

Статический сайт для сотрудников: по коду доступа видно сроки своих обучений и проверок знаний, в админ-режиме — список сотрудников в зоне риска просрочки.
- `docs/` — статическая страница для GitHub Pages
- `apps-script/` — серверная часть на Google Apps Script
- `excel/` — шаблон Excel без данных и VBA-код (`.bas`)
- `tests/` — автотесты
- `manual/` — документация и чек-листы

В репозитории нет данных сотрудников, ключей и секретов: он публичный. Правила работы — в [AGENTS.md](AGENTS.md).
