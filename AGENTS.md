# AGENTS.md — правила проекта «Сайт проверки знаний»

Этот файл читается перед любой работой над проектом. Он главнее привычек и удобства: если задание противоречит файлу — сначала спроси, потом делай.

## Цель проекта

Сайт для сотрудников предприятия (около 200 человек). Сотрудник вводит выданный ему код доступа и видит сроки своих обучений и проверок знаний. Есть отдельный админ-режим для руководителя: список сотрудников в зоне риска просрочки.

Данные ведутся в Excel и публикуются макросом VBA в Google Apps Script и Google Таблицу. Страница статическая, лежит на GitHub Pages в **публичном** репозитории, поэтому в репозитории не должно быть никаких данных сотрудников, ключей и секретов.

Сайт публикуется на GitHub Pages из ветки `main`, папки `/docs`. Всё содержимое `docs/` публично. Документация проекта лежит в `manual/` и не публикуется как сайт.

## Стек

- Фронтенд: чистые HTML, CSS, JavaScript, без фреймворков.
- Хостинг: GitHub Pages — публикация из ветки `main`, папка `/docs`; всё содержимое `docs/` публично.
- Документация: лежит в `manual/`, как сайт не публикуется.
- Серверная часть: Google Apps Script.
- Хранилище данных: Google Таблица.
- Загрузка данных: макрос VBA в Excel (Windows, Excel Desktop).
- Тесты: Node.js, встроенный раннер `node --test`, без внешних тестовых библиотек.

## Структура каталогов

```
docs/          статическая страница, публикуется GitHub Pages (index.html, admin.html, sw.js, manifest.json)
docs/js/       скрипты страницы
docs/css/      стили
docs/icons/    иконки
apps-script/   исходный код Google Apps Script
excel/         только шаблон Excel без реальных данных + VBA-код в текстовых файлах (.bas)
tests/         автотесты
manual/        документация (инструкции, чек-листы), как сайт не публикуется
```

Пустые каталоги держатся в git файлом `.gitkeep`.

## Договорённости

### Интерфейс

- Язык интерфейса — только русский.

### Цвета

- Основной фон: белый или таёжно-зелёный `#2B5E4A`.
- Основной текст: графитовый `#1D2126`.
- Тёмно-синий `#2C4153` — допускается редко.
- Акцент: бирюзовый `#5FB9CF` (RGB 95, 185, 207).
- Белый `#FFFFFF`.
- Таёжно-зелёный и тёмно-синий не использовать вместе.
- Статус всегда выражается цветом **И** текстом — одним цветом нельзя.

### Производительность

Сайт должен быть простым, быстро загружаться и работать на старых телефонах (iOS и Android).

### Роли

- Сотрудник — вход по коду доступа.
- Администратор — вход по отдельному длинному ключу (админ-ключ).

### Идентификаторы

- Внутренний № сотрудника (`E0001`, `E0002`, …) — ключ связи данных.
- Код доступа — 10 символов, группы `XXXXX-XXXXX`, регистр не важен, без символов `0`, `O`, `1`, `I`. Используется только для входа.

### Статусы записей

«В норме», «Скоро срок» (порог берётся из настроек, по умолчанию 30 дней), «Просрочено», «Бессрочно», «Данные на проверке».

### Данные на сайте

Разрешены только: ФИО, должность, обучения, даты, контакт ответственного. Email сотрудников видит только администратор. Дата рождения, телефон, адрес не используются.

## Правила кода

- Простой читаемый код; комментарии на русском там, где логика неочевидна.
- Расчёты выносятся в чистые функции (вход — данные, выход — результат, без побочных эффектов).
- Никакой логики в HTML-разметке: разметка только описывает структуру.
- Без внешних библиотек и CDN без согласования.
- Без внешних запросов, кроме одного адреса Google Apps Script.

## Запреты

- Не добавлять зависимости и npm-пакеты без явной причины и согласия заказчика.
- Не создавать и не коммитить ключи, пароли, токены, ссылки с секретами, реальные данные сотрудников.
- Не менять этот файл без явного указания в задании.
- Не ломать результат предыдущих шагов.
- Не утверждать, что что-то проверено, если это не запускалось; прямо писать, что проверить не удалось.

## Команды

- Сборки нет — сайт статический.
- Тесты: `node --test tests/`.
- Команды запуска сайта и работы с макросами будут добавлены на следующих шагах.

## Порядок работы

- Один шаг плана за раз; шаги не смешивать.
- В конце каждого шага — отчёт: список файлов, принятые решения, как проверить вручную, что отличается от задания.
- Коммит создаётся только с разрешения заказчика.

## Словарь терминов

- **Снимок** — полный набор опубликованных данных на момент публикации.
- **Зона риска** — записи со статусом «Скоро срок» или «Просрочено».
- **Код доступа** — 10 символов (`XXXXX-XXXXX`), только для входа сотрудника.
- **Внутренний №** — идентификатор сотрудника (`E0001`, …), ключ связи данных.
- **Админ-ключ** — отдельный длинный ключ для входа в админ-режим.
- **Ключ публикации** — используется только макросом, хранится вне репозитория.
